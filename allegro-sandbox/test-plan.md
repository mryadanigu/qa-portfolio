# Allegro Sandbox – Test Plan

**Project:** Allegro Sandbox  
**Environment:** Web (Chrome, Firefox, Edge)  
**Tester:** Yared  
**Version:** Sandbox v1.0  

---

## Objectives
- Validate core marketplace functionality  
- Identify functional and UI defects  
- Ensure smooth user experience  

---

## Scope
**In Scope:**  
- User registration and login  
- Product search and filtering  
- Product details and availability  
- Cart operations  
- Checkout flow  

**Out of Scope:**  
- Performance testing  
- Security testing  
- Mobile app testing  

---

## Test Strategy
- Manual testing of all user flows  
- Smoke testing before execution  
- Exploratory testing for edge cases  
- Regression testing for repeated actions  

---

## Entry Criteria
- Test environment ready  
- Test data prepared  

---

## Exit Criteria
- All critical test cases executed  
- High-severity bugs reported
