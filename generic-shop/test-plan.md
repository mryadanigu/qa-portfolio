# Generic Shop – Test Plan

**Project:** Generic Shop  
**Environment:** Web (Chrome, Firefox)  
**Tester:** Yared  
**Version:** v1.0  

---

## Objectives
- Validate shopping workflow  
- Identify usability and functional defects  
- Ensure smooth checkout experience  

---

## Scope
**In Scope:**  
- Homepage and navigation  
- Product catalog and filtering  
- Cart management  
- Checkout process  

**Out of Scope:**  
- Mobile app testing  
- Performance testing  

---

## Test Strategy
- Manual testing of core flows  
- Exploratory testing for edge cases  
- Regression testing for repeated actions  

## Entry Criteria
- Test environment ready  
- Test data prepared  

## Exit Criteria
- All test cases executed  
- High and critical defects logged
